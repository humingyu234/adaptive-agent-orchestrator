# AAO Phase Handoff

Keep handoffs factual and short.

Include:

```text
Current slice:
Goal:
Runtime path completed:
Real:
Fake/mock:
Artifact only:
Files changed:
Tests run:
Result:
Reviewer result:
Known risks:
Next recommended step:
Safe to proceed:
```

Do not say "mostly done" without file/test evidence.
Do not hide dirty files.
Do not claim a path is real when it used fake worker, deterministic fixture, or sample demo data.
